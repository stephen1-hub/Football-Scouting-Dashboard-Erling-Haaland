# ⚽ Football-Scouting-Dashboard-Erling-Haaland (2025/26)

A football analytics scouting dashboard built with **Python and Streamlit**.  
It analyzes Erling Haaland’s attacking performance using **xG metrics, shot profiling, and situation-based finishing data**.

The goal is to replicate a **professional scouting report system (Opta-style)** for elite striker evaluation.

---

## 📊 Key Features

- 📈 Player performance overview (Goals, xG, xA, xG/90)
- 🎯 Shot zone distribution (Out of box, Penalty area, Six-yard box)
- 🦶 Shot type breakdown (Left foot, Right foot, Head)
- ⚽ Situation analysis (Open play, Penalties, Set pieces, Corners)
- 🧠 Scouting report summary (strengths & weaknesses)
- 🎮 FIFA-style attribute card (elite striker profiling)

---

## 🧠 Key Insights

- 🇳🇴 91 shots inside the penalty area → elite box positioning
- ⚽ 0.86 xG/90 → world-class attacking output
- 🔥 Strong left-foot dominance as primary finishing tool
- 📉 Limited creative involvement (low xA contribution)
- 🧩 Highly system-dependent but extremely efficient scorer
